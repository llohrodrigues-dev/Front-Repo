# Frontend Portfolio

## Sobre

Este é o projeto final da Semana 8 e a principal vitrine da trilha. A página apresenta minha evolução e os projetos que desenvolvi desde os fundamentos de HTML até React.

## Tecnologias utilizadas

- React;
- JavaScript;
- CSS responsivo;
- Fetch API;
- API pública do GitHub.

## Funcionalidades

- apresentação da trilha;
- projetos selecionados;
- links para o código de cada entrega;
- carregamento dos repositórios públicos pela API do GitHub;
- estados de carregamento, vazio e erro;
- navegação responsiva e acessível.

## Como executar

```bash
npm install
npm run dev
```

## Decisões do projeto

Mantive a aplicação em uma única página porque o conteúdo é curto e o roteamento não fez parte da trilha. Separei o cabeçalho, os cartões e a consulta ao GitHub em componentes para deixar o código fácil de localizar.

## Limitações

Os projetos apontam para o código no GitHub e ainda não possuem páginas de demonstração separadas. A API do GitHub também possui limite de requisições para acessos sem autenticação.

## O que aprendi

Consegui reunir componentes, propriedades, estado, efeitos, consumo de API, tratamento de erros, responsividade e acessibilidade em uma entrega final que representa a evolução das oito semanas.
