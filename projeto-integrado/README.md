# Projeto integrado - Estante aberta

## Sobre

Este é o projeto da Semana 7. Reuni React e consumo de API em uma busca de livros simples e responsiva.

## Tecnologias utilizadas

- React;
- JavaScript;
- CSS;
- Fetch API;
- Open Library Search API.

## Funcionalidades

- formulário controlado;
- busca por título;
- componentes para formulário, lista e cartão;
- estados inicial, carregando, sucesso, vazio e erro;
- até nove resultados;
- links para os detalhes dos livros;
- mensagens acessíveis e navegação por teclado.

## Como executar

```bash
npm install
npm run dev
```

## O que aprendi

A principal diferença para o projeto da Semana 4 foi guardar a busca e os resultados no estado do React. Também consegui separar a lista e os cartões em componentes menores.

## Dificuldades

Foi necessário cuidar para limpar os resultados anteriores enquanto uma nova busca está carregando e mostrar mensagens diferentes para erro e lista vazia.
