Primeiros passos com CSS3

CSS inline é aplicado direto na tag. Ele serve para mudar uma parte específica do conteúdo.

CSS interno fica dentro da tag style, no cabeçalho da página. Já o CSS externo fica em um arquivo separado, como o style.css, para deixar o código mais organizado.
