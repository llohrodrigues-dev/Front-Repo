# Aula 01 - Estrutura básica do HTML

## O que aprendi

Nesta primeira aula criei uma página pequena para conhecer a estrutura principal do HTML.

## Conceitos praticados

- declaração do tipo de documento;
- tags `html`, `head` e `body`;
- idioma da página;
- título da aba;
- título e parágrafo no conteúdo.

## Minhas anotações

Foi interessante perceber que o conteúdo visível fica dentro do `body`, enquanto informações como o título da aba ficam no `head`.

## Dificuldades

Ainda preciso praticar a ordem das tags para lembrar de fechar cada elemento no lugar certo.

## Próximo passo

Praticar títulos, parágrafos e quebras de linha.
