# Aula 03 - Formatação de texto

## O que aprendi
Aprendi a deixar o texto com estilo, como negrito, itálico, destaque, sublinhado e até texto pequeno.

## Tags que conheci

- em
- mark
- small
- del
- ins
- sub

Eu achei interessante porque dá para deixar o texto mais bonito sem precisar de CSS.
