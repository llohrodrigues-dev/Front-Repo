# Projeto Institucional - Conecta Soluções Digitais

Este foi o meu primeiro projeto maior durante a trilha de HTML5. Eu criei um site institucional fictício com páginas simples e tentei organizar tudo de forma clara.

## Sobre o projeto

O projeto foi feito para representar uma empresa fictícia chamada Conecta Soluções Digitais. A ideia era criar um site com uma página inicial, informações sobre a empresa, serviços e uma área de contato. Tudo foi desenvolvido com HTML5 puro.

## Páginas criadas

- index.html: página inicial com a apresentação da empresa.
- sobre.html: página com a história e os valores da empresa.
- servicos.html: página com os serviços oferecidos.
- contato.html: página com um formulário simples de contato.

## Tecnologias utilizadas

- HTML5

## Conceitos aplicados

- Estrutura HTML5.
- Tags semânticas.
- Links entre páginas.
- Imagens.
- Listas.
- Formulários.
- Acessibilidade básica.
- Organização de arquivos.

## O que aprendi

Eu aprendi a organizar melhor as páginas HTML e a pensar mais na estrutura antes de escrever o código. Também comecei a entender melhor como as tags funcionam juntas e como deixar o conteúdo mais claro para quem visita a página.

## Dificuldades

Foi um pouco difícil organizar várias páginas e lembrar de todas as tags. Também tive um pouco de dificuldade para pensar na estrutura do conteúdo antes de começar a escrever.

## Melhorias futuras

No futuro eu quero aprender CSS para deixar o site mais bonito. Também quero melhorar a parte visual e aprender a fazer páginas mais responsivas.
