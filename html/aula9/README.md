# Aula 09 - Imagens no HTML

## O que aprendi
Aprendi a colocar imagens nas páginas e a usar textos alternativos para explicar o que aparece.

## Tags que conheci
- img
- src
- alt
- width
- height

## Minhas anotações
Eu achei interessante porque as páginas começaram a ficar mais visualmente completas.

## Dificuldades
Às vezes eu esqueço de colocar o alt, mas percebo que isso ajuda bastante na acessibilidade.

## Próximo passo
Quero praticar mais com imagens diferentes e tamanhos variados.
