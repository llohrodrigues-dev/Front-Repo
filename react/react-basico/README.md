# React básico - Painel de estudos

## Sobre

Este projeto encerra a Semana 5. Criei uma lista de estudos para reunir os fundamentos que pratiquei com React.

## Conceitos praticados

- componentes funcionais e JSX;
- propriedades e composição;
- eventos;
- estado local com `useState`;
- formulário controlado;
- listas com chaves;
- renderização condicional.

## Funcionalidades

- adicionar uma tarefa;
- marcar uma tarefa como concluída;
- remover uma tarefa;
- validar o campo vazio;
- informar mudanças com uma mensagem acessível.

## Como executar

```bash
npm install
npm run dev
```

## O que aprendi

Percebi que o estado guarda os dados que podem mudar na tela. Quando adiciono, concluo ou removo uma tarefa, o React renderiza novamente a lista com os dados atualizados.
