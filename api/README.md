# Semana 4 - Consumo de APIs

Nesta etapa comecei a buscar dados externos com JavaScript. As aulas avançam aos poucos, começando pelo formato JSON e chegando a uma página que pesquisa informações em uma API pública.

## Aulas

1. conceitos de API e JSON;
2. primeira requisição com `fetch`;
3. Promises com `then` e `catch`;
4. resposta HTTP e tratamento de erros;
5. funções assíncronas com `async` e `await`;
6. listas e estados da interface;
7. exercício de busca com parâmetros.

## Entrega da semana

O projeto final está em `projeto-api/`. Ele permite buscar livros pela API pública da Open Library e informa os estados de carregamento, sucesso, resultado vazio e erro.
