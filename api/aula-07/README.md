# Aula 07 - Buscando com parâmetros

## Objetivo

Praticar uma busca em que o valor digitado no formulário faz parte do endereço enviado para a API.

## Conceitos praticados

- formulário de busca;
- parâmetro na URL;
- filtro oferecido pela API;
- resposta com vários itens;
- resultado vazio;
- carregamento e erro;
- mensagens acessíveis.

## Minhas anotações

O trecho depois do ponto de interrogação envia um parâmetro para a API. Neste exercício, `userId` informa de qual usuário quero receber as publicações.

## Dificuldades

Eu precisei tratar uma lista vazia como um resultado válido. Não encontrar publicações é diferente de uma falha na requisição.

## Revisão da semana

Consegui juntar formulário, eventos, DOM, funções, arrays, `fetch`, `async`, `await` e tratamento de erros. Agora posso aplicar esses conteúdos em um projeto separado.
