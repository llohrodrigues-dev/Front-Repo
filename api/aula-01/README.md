# Aula 01 - Conhecendo APIs e JSON

## O que aprendi

Nesta aula conheci a ideia de API como uma forma de comunicação entre sistemas. Também aprendi que muitas APIs enviam os dados no formato JSON.

## Conceitos praticados

- diferença entre uma API do navegador e uma API de terceiros;
- dados organizados em pares de chave e valor;
- texto no formato JSON;
- conversão de JSON com `JSON.parse()`;
- acesso às propriedades de um objeto.

## Minhas anotações

O JSON se parece bastante com um objeto do JavaScript, mas normalmente chega como texto. Antes de utilizar seus valores, preciso converter esse texto.

## Dificuldades

Precisei observar as aspas e as vírgulas, porque um JSON escrito de forma incorreta não pode ser convertido.
