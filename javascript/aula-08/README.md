# Aula 08 - Operadores relacionais e lógicos

## O que aprendi

Aprendi a comparar valores e a combinar resultados lógicos. As comparações produzem `true` ou `false`.

## Conceitos praticados

- operadores `>`, `<`, `>=` e `<=`;
- igualdade estrita com `===`;
- diferença estrita com `!==`;
- operadores lógicos `&&`, `||` e `!`;
- criação de expressões booleanas.

## Minhas anotações

Preferi usar igualdade estrita porque ela compara o valor e o tipo. Dei nomes às comparações para facilitar a leitura do exemplo.

## Dificuldades

Combinar várias condições exige atenção. Separar cada resultado em uma constante tornou o raciocínio mais simples.
