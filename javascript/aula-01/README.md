# Aula 01 - O que o JavaScript pode fazer

## O que aprendi

Nesta primeira aula conheci o papel do JavaScript nas páginas. HTML organiza o conteúdo, CSS cuida da aparência e JavaScript permite criar comportamentos e interações.

## Conceitos praticados

- diferença entre HTML, CSS e JavaScript;
- exemplos de páginas interativas;
- uso do console do navegador;
- separação de responsabilidades entre as tecnologias.

## Minhas anotações

Percebi que JavaScript não substitui HTML e CSS. As três tecnologias trabalham juntas, mas cada uma tem uma função diferente.

## Dificuldades

No começo foi um pouco confuso separar o que é comportamento do que é apenas aparência.
