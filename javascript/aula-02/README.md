# Aula 02 - Como o JavaScript surgiu

## O que aprendi

Nesta aula conheci um pouco da história do JavaScript e entendi como a linguagem se tornou uma das bases da web.

## Conceitos estudados

- criação do JavaScript para os navegadores;
- evolução da linguagem;
- padrão ECMAScript;
- diferença entre Java e JavaScript;
- ferramentas usadas para escrever e testar código.

## Minhas anotações

O nome parecido com Java me confundia, mas agora entendi que são linguagens diferentes. Também descobri que o navegador já possui ferramentas para executar JavaScript.

## Próximo passo

Preparar o ambiente e aprender formas simples de testar os primeiros comandos.
