# Aula 15 - Arrays

## O que aprendi

Aprendi a guardar vários valores relacionados em uma única variável e a percorrer esses valores para montar uma lista.

## Conceitos praticados

- criação de arrays;
- posições dos elementos;
- propriedade `length`;
- inclusão com `push()`;
- repetição com `for...of`;
- renderização de itens no DOM.

## Minhas anotações

As posições começam em zero, mas o `for...of` permite acessar cada valor diretamente quando não preciso do índice.

## Dificuldades

Foi estranho no começo lembrar que o primeiro item está na posição zero.

## Próximo passo

Organizar instruções em funções reutilizáveis.
