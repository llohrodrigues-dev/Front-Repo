# Aula 14 - Repetições com for

## O que aprendi

Usei o laço `for` para gerar os dez resultados de uma tabuada e colocá-los em uma lista da página.

## Conceitos praticados

- estrutura do laço `for`;
- início, condição e incremento;
- criação de elementos com `createElement()`;
- inclusão de itens com `appendChild()`;
- limpeza do resultado anterior.

## Minhas anotações

O `for` foi adequado porque eu já sabia que o multiplicador iria de 1 até 10.

## Dificuldades

Precisei limpar a lista antes de gerar uma nova tabuada para não acumular resultados antigos.

Guardar vários valores em arrays e percorrê-los.
