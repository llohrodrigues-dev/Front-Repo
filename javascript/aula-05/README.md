# Aula 05 - Variáveis e tipos primitivos

## O que aprendi

Aprendi que variáveis guardam informações que podem ser usadas pelo programa. Também conheci os tipos `string`, `number` e `boolean`.

## Conceitos praticados

- declaração com `const` e `let`;
- textos, números e valores lógicos;
- alteração de uma variável criada com `let`;
- operador `typeof`;
- nomes claros para variáveis.

## Minhas anotações

Usei `const` quando o valor não precisava mudar e `let` para a idade, que foi atualizada durante o exemplo.

## Dificuldades

Ainda preciso prestar atenção para não colocar números entre aspas quando quero fazer cálculos.

## Próximo passo

Receber dados do usuário e converter textos em números.
