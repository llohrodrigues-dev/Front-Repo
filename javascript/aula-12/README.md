# Aula 12 - Condições encadeadas

## O que aprendi

Criei uma verificação com três resultados possíveis: aprovação, recuperação ou reprovação.

## Conceitos praticados

- condições encadeadas;
- uso de `else if`;
- ordem das verificações;
- comparação de números decimais;
- resposta próxima ao formulário.

## Minhas anotações

Comecei pela maior nota. Quando uma condição é verdadeira, as próximas opções não precisam ser verificadas.

## Dificuldades

A ordem das condições importa. Uma comparação muito ampla no começo poderia impedir as outras respostas.
