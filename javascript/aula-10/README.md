# Aula 10 - Eventos do DOM

## O que aprendi

Aprendi a executar uma ação quando o usuário utiliza um botão. Criei um contador que também pode ser limpo.

## Conceitos praticados

- evento `click`;
- método `addEventListener()`;
- funções ligadas a eventos;
- atualização de conteúdo;
- região dinâmica com `aria-live`.

## Minhas anotações

Usei botões reais porque as ações também precisam funcionar pelo teclado. O `aria-live` ajuda a comunicar a mudança do contador ao leitor de tela.

## Dificuldades

No início esqueci que a quantidade precisava ficar fora das funções para manter o valor entre os cliques.

## Próximo passo

Usar condições para o programa tomar decisões.
