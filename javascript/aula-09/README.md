# Aula 09 - Introdução ao DOM

## O que aprendi

Conheci o DOM, que representa os elementos da página para que o JavaScript consiga encontrá-los e modificá-los.

## Conceitos praticados

- árvore de elementos da página;
- seleção por ID e classe;
- `document.querySelector()`;
- armazenamento de elementos em constantes;
- alteração segura de texto com `textContent`.

## Minhas anotações

Os seletores lembram os usados no CSS. Guardar cada elemento em uma constante deixou claro qual parte da página seria alterada.

## Dificuldades

Eu precisava lembrar de usar `#` para ID e `.` para classe.
