# Aula 06 - Tratamento de dados

## O que aprendi

Nesta aula tratei dados recebidos pelo `prompt()`. Como a entrada chega em formato de texto, usei `Number()` antes de fazer uma soma.

## Conceitos praticados

- entrada de dados;
- conversão com `Number()`;
- diferença entre soma e concatenação;
- template strings;
- exibição do resultado na página.

## Minhas anotações

Sem a conversão, os valores seriam colocados lado a lado como texto. Esse detalhe muda completamente o resultado.

## Dificuldades

Foi necessário lembrar que o tipo do dado importa antes de realizar uma operação.

## Próximo passo

Praticar operadores aritméticos, atribuição e precedência.
