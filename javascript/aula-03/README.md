# Aula 03 - Dando os primeiros passos

## O que aprendi

Aprendi a ligar um arquivo JavaScript a uma página HTML e a consultar mensagens no console do navegador.

## Conceitos praticados

- criação do arquivo `script.js`;
- atributo `src` da tag `script`;
- comando `console.log()`;
- ordem de carregamento da página.

## Minhas anotações

Coloquei a tag `script` no final do `body`. Assim, o conteúdo HTML aparece antes de o navegador carregar o código JavaScript.

## Dificuldades

Precisei prestar atenção ao caminho do arquivo. Quando o nome ou a pasta estão errados, nada aparece no console.

## Próximo passo

Criar um primeiro script que converse com o usuário e altere o conteúdo da página.
