# Aula 13 - Repetições com while

## O que aprendi

Aprendi a repetir um bloco enquanto uma condição for verdadeira. Também comparei `while` com `do...while`.

## Conceitos praticados

- laço `while`;
- laço `do...while`;
- variável de controle;
- incremento e decremento;
- condição de parada.

## Minhas anotações

No `while`, a condição é verificada antes. No `do...while`, o bloco executa pelo menos uma vez.

## Dificuldades

É importante atualizar o contador. Sem isso, a condição continuaria verdadeira e a repetição não terminaria.

## Próximo passo

Usar o laço `for` quando a quantidade de repetições já estiver definida.
