# Aula 11 - Condições simples e compostas

## O que aprendi

Usei `if` e `else` para mostrar uma resposta diferente de acordo com a idade informada.

## Conceitos praticados

- condição simples;
- condição composta;
- blocos `if` e `else`;
- evento de envio do formulário;
- `preventDefault()`;
- conversão do valor de um campo.

## Minhas anotações

A condição é lida como uma pergunta. Se o resultado for verdadeiro, o primeiro bloco é executado; caso contrário, o programa segue para o `else`.

## Dificuldades

Precisei lembrar de converter o valor do campo para número antes da comparação.

## Próximo passo

Trabalhar com mais de duas possibilidades usando condições encadeadas.
