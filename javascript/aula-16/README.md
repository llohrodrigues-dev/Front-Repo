# Aula 16 - Funções

## O que aprendi

Aprendi a criar funções com parâmetros e retorno. Separei o cálculo da média da verificação da situação.

## Conceitos praticados

- declaração de funções;
- parâmetros e argumentos;
- palavra-chave `return`;
- responsabilidade de cada função;
- reutilização de resultados.

## Minhas anotações

As funções deixaram o evento de envio mais curto. Cada uma possui um nome que explica o trabalho realizado.

## Dificuldades

No começo confundi o valor recebido no parâmetro com o valor devolvido pelo `return`.

## Próximo passo

Reunir DOM, eventos, condições e funções em uma validação de formulário.
