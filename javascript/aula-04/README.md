# Aula 04 - Criando o primeiro script

## O que aprendi

Nesta aula criei um script pequeno que recebe o nome do usuário e mostra uma saudação na página.

## Conceitos praticados

- entrada de dados com `prompt()`;
- armazenamento de um valor;
- seleção de um elemento pelo identificador;
- alteração de texto com `textContent`;
- interpolação de texto com template string.

## Minhas anotações

Foi interessante ver a página responder a uma informação digitada. Usei `textContent` para que a mensagem fosse exibida como texto comum.

## Dificuldades

Precisei conferir as aspas e os sinais usados na template string.

## Próximo passo

Entender melhor como guardar valores em variáveis e conhecer os tipos primitivos.
