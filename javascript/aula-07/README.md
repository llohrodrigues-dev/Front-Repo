# Aula 07 - Operadores aritméticos

## O que aprendi

Pratiquei cálculos com JavaScript e conheci operadores de atribuição que ajudam a atualizar um valor existente.

## Conceitos praticados

- adição, subtração, multiplicação e divisão;
- resto da divisão e potência;
- ordem de precedência;
- atribuição com `+=`;
- incremento de valores.

## Minhas anotações

O operador de resto pode ajudar a descobrir, por exemplo, se um número é par. Também percebi que parênteses deixam cálculos maiores mais claros.

## Próximo passo

Comparar valores e combinar condições usando operadores relacionais e lógicos.
