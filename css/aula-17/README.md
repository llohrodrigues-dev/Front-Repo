## O que aprendi

Eu aprendi que o CSS pode deixar uma página muito mais bonita e organizada. No começo parecia tudo meio confuso, mas com o tempo fui entendendo melhor cada parte. Eu consegui perceber que cada propriedade tem uma função e que, quando juntamos várias coisas, a página fica com uma aparência bem melhor.

## Minhas maiores dificuldades

As partes que mais me confundiram foram o Flexbox, o Grid e o Position. Eu precisei estudar com calma e testar várias vezes para entender como cada um funcionava. Também achei um pouco difícil lembrar a diferença entre margin e padding no começo.

## O que gostei de aprender

Eu gostei bastante de ver as páginas mudando de aparência quando eu aplicava novas propriedades. Foi muito legal perceber que com poucas mudanças já dava para deixar o site mais bonito e mais organizado.

## O que preciso praticar mais

Eu ainda preciso praticar mais para lembrar tudo com mais facilidade. Quero treinar mais o Flexbox, o Grid e as Media Queries, porque essas partes ainda exigem mais atenção. Também quero praticar mais para criar layouts com mais calma e sem ficar tão perdido.

## Próximo desafio

O próximo passo será usar todos esses conhecimentos para estilizar completamente o projeto institucional que foi desenvolvido durante a trilha de HTML. Quero tentar aplicar tudo que aprendi e deixar a página com uma aparência bem melhor.
