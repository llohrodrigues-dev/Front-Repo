# Aula 06 - Bordas e Cantos Arredondados

## O que aprendi

Nesta aula aprendi que as bordas ajudam a destacar elementos da página. Com elas, dá para deixar o conteúdo mais organizado e com uma aparência diferente.

## Conceitos praticados

- border
- border-width
- border-style
- border-color
- border-radius

## Minhas anotações

Eu gostei de testar diferentes tipos de borda, como sólida, tracejada e pontilhada. Também achei interessante ver que os cantos arredondados deixam a página mais leve.

## Dificuldades

Foi necessário testar alguns estilos para entender melhor o resultado de cada borda. No começo parecia difícil, mas depois ficou mais claro.

## Próximo passo

Pretendo aprender a organizar melhor os elementos da página com novas propriedades do CSS.
