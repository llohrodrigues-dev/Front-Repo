# Aula 04 - Fontes e Tipografia

## O que aprendi

Nesta aula eu aprendi que o CSS também ajuda a dar forma ao texto. Com algumas propriedades simples, dá para deixar o conteúdo mais bonito e mais fácil de ler.

## Conceitos praticados

- font-family
- font-size
- font-weight
- font-style
- text-align
- line-height

## Minhas anotações

Eu gostei de perceber que mudar a fonte e o alinhamento faz muita diferença na aparência da página. Mesmo com poucas propriedades, já dá para criar um resultado bem melhor.

## Dificuldades

No começo fiquei um pouco confuso para lembrar a diferença entre font-weight e font-style, mas com exemplos ficou mais claro.

## Próximo passo

Na próxima aula quero continuar aprendendo mais sobre CSS e tentar criar páginas ainda mais organizadas.
