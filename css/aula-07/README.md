# Aula 07 - Box Model

## O que aprendi

Nesta aula aprendi que o Box Model é a forma como o CSS organiza os elementos da página. A margem fica fora do elemento e o padding fica dentro, criando espaços diferentes.

## Conceitos praticados

- Box Model
- margin
- padding

## Minhas anotações

Eu percebi que o padding deixa o conteúdo mais afastado da borda, enquanto a margin afasta o elemento de outros elementos da página.

## Dificuldades

No começo foi fácil confundir margin com padding, mas praticando com exemplos ficou mais claro.

## Próximo passo

Pretendo aprender novas formas de organizar os elementos da página para deixar as páginas ainda melhores.
