# Aula 05 - Backgrounds

## O que aprendi

Nesta aula aprendi que o CSS também pode deixar a página mais interessante usando imagens e cores de fundo. Foi legal ver como o background pode mudar bastante a aparência do site.

## Conceitos praticados

- background-color
- background-image
- background-repeat
- background-position
- background-size

## Minhas anotações

Eu percebi que uma imagem de fundo pode deixar a página mais bonita, mas é importante escolher uma imagem que não atrapalhe a leitura do texto.

## Dificuldades

No começo achei um pouco difícil entender como a imagem se encaixava na página, mas praticando ficou mais claro.

## Próximo passo

Na próxima aula quero continuar aprendendo mais sobre CSS e descobrir novas formas de deixar as páginas mais organizadas.
