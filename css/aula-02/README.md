# Aula 02 - Seletores, Classes e IDs

## O que aprendi

Nessa aula eu aprendi que o CSS pode ser aplicado de diferentes formas usando seletores. Também entendi que classes e IDs ajudam a organizar melhor os estilos.

## Conceitos praticados

- Seletores
- Classes
- IDs

## Minhas anotações

Eu percebi que o seletor por elemento muda todos os elementos iguais, a classe pode ser usada em vários lugares e o ID é mais específico.

## Dificuldades

Uma dificuldade comum para quem está começando é lembrar quando usar classe ou ID.

## Próximo passo

Vou continuar aprendendo novas propriedades do CSS para deixar as páginas ainda mais bonitas.
