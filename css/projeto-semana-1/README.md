# Projeto da Semana 1

## Objetivo

Criar uma cópia do projeto institucional da trilha de HTML com um visual mais organizado e bonito usando os conhecimentos de CSS aprendidos durante a semana.

## Tecnologias utilizadas

- HTML
- CSS
- Responsividade

## Estrutura do projeto

- index.html
- sobre.html
- servicos.html
- contato.html
- style.css
- README.md

## Recursos aplicados

- Seletores
- Classes
- Cores
- Fontes
- Backgrounds
- Bordas
- Border Radius
- Margin
- Padding
- Flexbox
- Grid
- Hover
- Focus
- Transition
- Transform
- Media Queries

## Responsividade

A página foi organizada para funcionar bem em desktop, notebook, tablet e celular. Os elementos mudam de posição ou passam a ocupar mais espaço quando a tela fica menor.

## O que aprendi durante a construção

Aprendi que, com organização e prática, dá para transformar um site simples em algo mais agradável. Também percebi que a responsividade é muito importante para deixar a navegação mais fácil em telas diferentes.

## Melhorias futuras

Pretendo continuar praticando para melhorar ainda mais a organização do layout e aprender novas formas de deixar as páginas mais bonitas.
