# Aula 12 - Introdução ao CSS Grid

## O que aprendi

Nesta aula aprendi que o CSS Grid ajuda a organizar elementos em linhas e colunas. Ele fica muito útil quando quero criar uma grade com vários blocos.

## Conceitos praticados

- display: grid
- grid-template-columns
- grid-template-rows
- gap

## Minhas anotações

Eu percebi que o Grid é diferente do Flexbox porque ele organiza o layout em uma grade, enquanto o Flexbox funciona mais como uma linha ou coluna.

## Dificuldades

Foi preciso praticar para entender como definir linhas e colunas e como fazer os itens se encaixarem melhor.

## Próximo passo

Pretendo aprender como adaptar o layout para diferentes tamanhos de tela.
