# Aula 15 - Responsividade na Prática

## O que aprendi

Nesta aula aprendi que é possível adaptar uma página para diferentes tamanhos de tela usando CSS. Isso faz a página ficar mais organizada em desktop, tablet e celular.

## Conceitos praticados

- Flexbox
- Grid
- Margin
- Padding
- Border
- Border-radius
- Media Queries

## Minhas anotações

Eu percebi que pequenos ajustes no layout fazem muita diferença. A página ficou mais fácil de ler quando a tela ficou menor.

## Dificuldades

Foi necessário ajustar alguns elementos para que a página ficasse organizada em telas menores.
