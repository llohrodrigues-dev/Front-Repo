# Aula 11 - Flexbox Avançado

## O que aprendi

Nesta aula aprendi que o Flexbox também ajuda a organizar elementos de forma mais flexível. Com propriedades como flex-wrap, flex-grow e order, dá para ajustar melhor o layout das páginas.

## Conceitos praticados

- flex-wrap
- flex-grow
- order

## Minhas anotações

Eu percebi que o flex-wrap faz os cards quebrarem para outra linha quando não há espaço. O flex-grow faz um card ocupar mais espaço, e o order muda a ordem visual dos elementos.

## Dificuldades

Foi necessário experimentar diferentes valores para entender como cada propriedade altera o layout.

Pretendo aprender uma nova forma de criar layouts utilizando CSS Grid.
