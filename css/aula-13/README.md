# Aula 13 - Position

## O que aprendi

Nesta aula aprendi que a propriedade position ajuda a controlar onde os elementos aparecem na página. Cada valor faz o elemento se comportar de uma maneira diferente.

## Conceitos praticados

- static
- relative
- absolute
- fixed
- sticky

## Minhas anotações

Eu percebi que o static segue o fluxo normal, o relative se move um pouco, o absolute fica em relação a um ponto de referência, o fixed fica preso na tela e o sticky gruda enquanto a página rola.

## Dificuldades

Foi preciso experimentar diferentes posições para entender como cada uma funciona.

## Próximo passo

Pretendo aprender a adaptar páginas para diferentes tamanhos de tela.
