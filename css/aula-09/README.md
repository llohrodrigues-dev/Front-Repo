# Aula 09 - Introdução ao Flexbox

## O que aprendi

Nesta aula aprendi que o Flexbox ajuda a organizar elementos de forma mais simples. Com ele, dá para colocar os itens em linha ou em coluna sem muita dificuldade.

## Conceitos praticados

- display: flex
- flex-direction
- gap

## Minhas anotações

Eu percebi que o Flexbox facilita bastante quando quero colocar vários elementos em sequência. O row deixa os itens lado a lado e o column empilha os itens.

## Dificuldades

Foi necessário testar as direções row e column para entender melhor o funcionamento.

## Próximo passo

Pretendo aprender novas propriedades do Flexbox para alinhar melhor os elementos.
