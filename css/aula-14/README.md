# Aula 14 - Media Queries

## O que aprendi

Nesta aula aprendi que as Media Queries servem para mudar o layout da página conforme o tamanho da tela. Assim, a mesma página pode ficar melhor em tablet e celular.

## Conceitos praticados

- @media
- Ajustes para tablet
- Ajustes para celular

## Minhas anotações

Eu achei interessante ver como a mesma página pode mudar dependendo da largura da tela. Isso deixa o conteúdo mais organizado e mais fácil de ler.

## Dificuldades

Foi preciso testar diferentes larguras da janela para entender o comportamento das Media Queries.

## Próximo passo

Pretendo aprender a criar páginas totalmente responsivas.
