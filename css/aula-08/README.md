# Aula 08 - Propriedade Display

## O que aprendi

Nesta aula aprendi que a propriedade display mostra como um elemento se comporta na página. Alguns elementos ocupam a linha inteira, outros ficam lado a lado e outros podem ficar invisíveis.

## Conceitos praticados

- display: block
- display: inline
- display: inline-block
- display: none

## Minhas anotações

Eu percebi que o display block faz o elemento ocupar uma linha inteira, o inline fica junto com o texto e o inline-block permite ter largura e altura sem quebrar a linha.

## Dificuldades

Foi preciso testar várias vezes para entender por que cada tipo de display se comporta de maneira diferente.
