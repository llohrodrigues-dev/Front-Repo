# Aula 03 - Trabalhando com cores

## O que aprendi

Nesta aula eu aprendi que existem várias formas de representar cores no CSS. Algumas são mais fáceis de lembrar, como os nomes, e outras parecem mais técnicas, como HEX, RGB, RGBA e HSL.

## Conceitos praticados

- Nome das cores
- HEX
- RGB
- RGBA
- HSL

## Minhas anotações

Eu gostei de ver que cada forma pode dar um resultado diferente. Acho que com prática fica mais fácil escolher a melhor opção para cada página.

## Dificuldades

Foi um pouco difícil lembrar a diferença entre RGB, RGBA e HSL, mas estudar com exemplos ajudou bastante.

## Próximo passo

Nas próximas aulas eu quero aprender a melhorar ainda mais o visual das páginas.
