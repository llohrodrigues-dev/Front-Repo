Explorando as diferentes formas de utilizar cores no CSS

Cor por nome

Este exemplo usa uma cor pelo nome, como blue.

Cor em hexadecimal

Este exemplo usa uma cor em hexadecimal, como #3498db.

Cor em RGB

Este exemplo usa uma cor em RGB, como rgb(255, 99, 71).

Cor em RGBA

Este exemplo usa uma cor em RGBA, como rgba(0, 128, 0, 0.7).

Cor em HSL

Este exemplo usa uma cor em HSL, como hsl(300, 100%, 25%).

  • As cores podem ser escritas de várias formas.
