# Aula 16 - Pseudo-classes e Efeitos

## O que aprendi

Nesta aula aprendi que pequenos efeitos podem deixar a página mais agradável. Com hover, focus e transições, dá para dar mais vida aos elementos sem exagerar.

## Conceitos praticados

- :hover
- :focus
- transition
- transform

## Minhas anotações

Eu percebi que os efeitos ficam melhores quando são discretos. O hover e o focus deixam a interação mais clara, e as transições ajudam a suavizar as mudanças.

## Dificuldades

Foi preciso ajustar os valores das transições para que os efeitos não ficassem exagerados.
