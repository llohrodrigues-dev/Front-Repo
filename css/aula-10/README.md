# Aula 10 - Praticando Flexbox

## O que aprendi

Nesta aula pratiquei o uso de um container flexível para organizar vários cartões. Entendi melhor como o `flex-wrap` permite quebrar a linha quando não existe espaço suficiente.

## Conceitos praticados

- `display: flex`;
- espaçamento com `gap`;
- quebra de linha com `flex-wrap`;
- tamanho flexível dos itens com `flex`.

## Minhas anotações

No começo eu achava que precisava definir uma largura fixa para cada cartão. Usando `flex`, os elementos conseguem dividir o espaço e ainda se adaptar a telas menores.
